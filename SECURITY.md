# Security Policy / Sicherheitsrichtlinie

## Sicherheitslücke melden · Reporting a vulnerability

**Deutsch:** Bitte melde Sicherheitslücken vertraulich – nicht über öffentliche
Issues – per [GitHub Private Vulnerability Reporting](https://github.com/0xGI0/GitHub-Follower-Checker/security/advisories/new)
oder per E-Mail an <georgios@tertlidis.com>
(PGP: <https://tertlidis.com/pgp.asc>). Du bekommst innerhalb weniger Tage
eine Antwort.

**English:** Please report vulnerabilities confidentially – not via public
issues – through [GitHub private vulnerability reporting](https://github.com/0xGI0/GitHub-Follower-Checker/security/advisories/new)
or by e-mail to <georgios@tertlidis.com>
(PGP: <https://tertlidis.com/pgp.asc>). You will receive a reply within a
few days.

## Unterstützte Versionen · Supported versions

Sicherheitsfixes erhält nur die jeweils neueste Release-Version. /
Security fixes are provided for the latest release only.
